### 1. Install & Setup


### 2. Run the App
```bash

```

## 🆘 Need Help?

1. **Can't run npm?** → Install Node.js from https://nodejs.org
2. **Permission errors?** → Run: `chmod +x *.sh`
3. **Port in use?** → Kill process: `lsof -ti:5173 | xargs kill -9`
4. **More help?** → See [LOCAL-SETUP-GUIDE.md](./LOCAL-SETUP-GUIDE.md)
