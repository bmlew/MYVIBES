================================================================================
                    MYVIBES - Windows Quick Start
================================================================================

STEP 1: Open Command Prompt
----------------------------
Press: Windows Key + R
Type:  cmd
Press: Enter

STEP 2: Navigate to Project
----------------------------
cd C:\User\MyVibes

STEP 3: Run Setup
----------------------------
quick-setup.bat

STEP 4: Start App
----------------------------
npm run dev

STEP 5: Open Browser
----------------------------
http://localhost:5173
