📝 How Auto-Recovery Works Now:
1. User tries to sign in with orphaned account (user ID: 624d8d51...)
2. Supabase auth succeeds but business record is missing
3. System checks user metadata for business info
4. If metadata exists → Create full business record
5. If NO metadata → Create minimal business record with `needs_setup: true`
6. Yellow warning banner shows: "Account Setup Incomplete - Complete Settings"
7. User clicks "Complete Setup" → Opens Settings page
8. User updates business info → Account fully activated
