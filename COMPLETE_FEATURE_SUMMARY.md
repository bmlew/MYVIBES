## 📱 Mobile App Timeline (FAQ)

### **Q: Why does it take 6-8 weeks?**
**A:** You're not paying for 6-8 weeks of work. You're paying for:
- 100 hours of active development (12.5 days)
- 7-14 days of mandatory waiting (Apple/Google reviews)
- Buffer for rejections & bug fixes

**You cannot skip the waiting period!** Store reviews are beyond your control.

### **Q: Can we go faster?**
**A:** The fastest possible is ~5-6 weeks:
- Hire experienced React Native developer
- Use Expo for faster builds
- Start Apple/Google accounts early
- Use TestFlight beta testing
- Get approved first time (no rejections)

**Hard limits you cannot avoid:**
- App Store review: 1-3 days minimum
- Play Store review: 1-7 days minimum
- Build times: 15-30 min each

### **Q: What's included in 100 hours?**
**A:**
- Week 1: Setup & infrastructure (20h)
- Week 2: Core screens (20h)
- Week 3: Geolocation & maps (20h)
- Week 4: UI polish & features (20h)
- Week 5: iOS build & submission (10h)
- Week 6: Android build & submission (10h)

### **Q: How much code can we reuse?**
**A:** ~70% from web platform:
- API client (same endpoints)
- Business logic (same calculations)
- Distance utils (same formulas)
- Data models (same structure)

**Need to rebuild:**
- UI components (React Native, not HTML)
- Styling (StyleSheet, not CSS)
- Navigation (React Navigation)
- Native features (geolocation, maps)
