## 🚀 **Quick Start Path**

### **Today (30 minutes):**

```bash
# 1. Install Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android @capacitor/geolocation @capacitor/camera @capacitor/push-notifications @capacitor/haptics @capacitor/share @capacitor/status-bar @capacitor/splash-screen

# 2. Build web app
npm run build

# 3. Add platforms
npx cap add ios       # Mac only
npx cap add android

# 4. Open in IDE
npx cap open ios      # or
npx cap open android
```

**Result:** Your web app is now a native mobile app! 🎉

## 🚨 **Common Gotchas & Solutions**

### **1. "White screen on launch"**
**Cause:** Web app not built or synced  
**Fix:**
```bash
npm run build
npx cap sync
# Then rebuild in Xcode/Android Studio
```

### **2. "Location not working"**
**Cause:** Missing permissions  
**Fix:**
- iOS: Add to Info.plist (see setup guide)
- Android: Add to AndroidManifest.xml (see setup guide)

### **3. "Build failed in Xcode"**
**Cause:** Various (common on first build)  
**Fix:**
```
Product → Clean Build Folder
Product → Build
```

### **4. "Gradle sync failed"**
**Cause:** Android Studio caching  
**Fix:**
```
File → Invalidate Caches / Restart
```

### **5. "App crashes immediately"**
**Cause:** JavaScript error  
**Fix:**
- Open Safari → Develop → Simulator → Web Inspector
- Check console for errors
- Fix error in web code
- Rebuild
